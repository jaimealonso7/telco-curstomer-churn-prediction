# 📊 Customer Churn Prediction

Predicción de churn (abandono) de clientes utilizando **Machine Learning**. 

Este proyecto identifica clientes con alto riesgo de cancelar el servicio, permitiendo a la empresa tomar acciones preventivas de retención y reducir pérdidas de ingresos.

### 🎯 Objetivo del Proyecto
Predecir si un cliente abandonará el servicio (Churn = Yes) basándose en características demográficas, de uso y financieras.
